# JavaScript 学习笔记

> pink 老师 2025 最新前端基础课程 — JavaScript 配套代码

## 📖 简介

本项目记录了 JavaScript 前端基础学习的完整过程，涵盖 **JavaScript 基础语法** 和 **WebAPI（浏览器 API）** 两大模块，适合前端入门学习者参考和练习。

## 📂 目录结构

```
JS学习/
├── js基础/          # JavaScript 核心语法（27 个笔记 + 素材）
└── WebAPI/          # Web API 浏览器编程（36 个笔记 + 3 个综合案例）
```

## 🚀 使用方式

1. 直接在浏览器中打开对应的 `.html` 文件即可运行
2. 部分案例（轮播图、电梯导航、学成在线、综合案例）需要配套的 CSS/图片资源，请保持目录结构不变
3. 建议在 VS Code 中使用 **Live Server** 插件打开，以获得更好的开发体验
